# Roos Studio Branding Pack

This package contains a clean production-ready asset structure for `roosstudio.ch`.

## Folder structure

- `logos/` — full logos and icon variants
- `favicons/` — browser favicons
- `app-icons/` — PWA / mobile icons
- `social/` — Open Graph and social preview images
- `website/` — website support images
- `brand/` — color, type and usage documentation

## Notes

- Favicons use the simplified single-color icon for clarity.
- App icons use the gradient icon on a dark rounded square.
- The source provided was raster-generated, so this pack does **not** include a true vector SVG.
  If you want a native SVG later, it should be redrawn from the approved logo.
